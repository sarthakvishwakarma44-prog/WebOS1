# 🌐 WebOS v1.0

A browser-based operating system simulation built with HTML, CSS, and JavaScript.

WebOS is designed to look and feel like a simple desktop operating system while running completely inside a web browser.

## 🚀 Features

- 🖥️ Desktop environment
- 🪟 Application windows
- 📁 File Manager
- 📝 Notes application
- 🧮 Calculator
- ⚙️ Settings
- 📊 Task Manager
- 🎮 Games section
- 🔋 Real-time battery information
- 🕐 Real-time clock
- 🌐 Network status
- 💾 Local note saving
- 🔎 Start menu
- 📌 Taskbar
- 👋 WebOS welcome screen

## 🛠️ Technologies

- HTML5
- CSS3
- JavaScript
- Browser APIs
- LocalStorage
